# Musik latar teaser

Taruh **1 file musik** di folder ini dengan nama **`musik-teaser.mp3`**.

Kriteria:
- Instrumental (tanpa vokal), gaya *cinematic tech / epic corporate trailer*.
- Durasi 60-90 detik, ada **build-up** di awal dan **drop/klimaks** (buat reveal & montage).
- Sumber disarankan: **Pixabay Music** (pixabay.com/music) - bebas dipakai, tanpa atribusi.
  Kata kunci: `cinematic tech trailer`, `epic corporate`, `technology promo`.

Kalau folder ini masih kosong: Studio otomatis menyusun **musik cadangan ("trailer bed")** dari
`sfx/trailer-groove-perkusi` (pukulan sub tanpa nada), `sfx/trailer-pulse-panjang` (sustain), `sfx/boom-trailer-*`,
`sfx/braam-*`, dan `sfx/riser-blastoff`.
